# Code of Conduct

ShootDrop is built by people with very different backgrounds and experience levels. We want everyone,
from first-time contributors to seasoned engineers, to feel welcome.

**Do:** be respectful and patient, give constructive feedback about code (not people), assume good intent,
and help newcomers find their way.

**Don't:** harass, insult or demean anyone, post others' private information, or keep pushing after
someone has asked you to stop.

Maintainers may edit or remove comments, issues and PRs that break these rules, and may block repeat offenders.

To report a problem privately, contact the maintainer through [GitHub](https://github.com/nadeem74) or
[LinkedIn](https://www.linkedin.com/in/nadeem12).

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
