# ADR-002: Name "ShootDrop", MIT license

- Status: Accepted
- Date: 2026-11-23

## Decision

- Product, repo and app name: **ShootDrop**. Bundle ID: `io.github.<owner>.shootdrop`
  (set once the GitHub owner is final).
- License: **MIT**: short, permissive, widely understood by contributors.

## Consequences

- Every source file can be reused commercially by others; attribution is kept via the LICENSE file.
- Before the public launch: check the name on GitHub, the Mac App Store and a trademark search.
- AI model weights (v0.2) ship as a separate download under their own license, never inside the MIT repo.
